## 🚀 Overview

NEXTALK is a full-stack real-time messaging platform that combines secure communication with Artificial Intelligence.

Users can exchange messages instantly through WebSockets and use the integrated **Google Gemini API** to automatically summarize long conversations, making it easier to review discussions without reading every message.

The project demonstrates modern web development concepts including real-time communication, authentication, AI integration, REST APIs, and responsive UI design.

---

## ✨ Features

### 💬 Chat Features

- Secure User Authentication (JWT)
- Real-Time One-to-One Messaging
- Instant Message Delivery using Socket.IO
- Chat History Storage
- Online/Offline User Status
- Responsive UI
- User Profile Management

### 🤖 AI Features

- AI-Powered Chat Summarization
- One-Click Conversation Summary
- Powered by Google Gemini API
- Generates concise summaries for lengthy conversations
- Helps users quickly understand previous discussions
